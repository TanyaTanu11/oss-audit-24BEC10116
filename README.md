## About This Project
A structured audit of Git — the open source distributed version control system created by Linus Torvalds in 2005, licensed under GPL v2.

## Scripts

| Script | Description |
|--------|-------------|
| script1_system_report.sh | Displays system identity — kernel, user, uptime, date, OS license |
| script2_package_inspector.sh | Checks if Git is installed, shows version and philosophy note |
| script3_disk_auditor.sh | Audits key system directories for permissions and size |
| script4_log_analyzer.sh | Analyzes a log file and counts keyword occurrences |
| script5_manifesto.sh | Interactive open source manifesto generator |

## How to Run (on Linux/Mac)

### Requirements
- Bash shell
- Git installed

### Steps
```bash
chmod +x *.sh
./script1_system_report.sh
./script2_package_inspector.sh
./script3_disk_auditor.sh
./script4_log_analyzer.sh
./script5_manifesto.sh
